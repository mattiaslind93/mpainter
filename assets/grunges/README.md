# Built-in CC0 photo-scanned grunge maps

These eight 512×512 8-bit grayscale PNG maps are derived from real photo-scanned CC0 1.0 Public Domain surface imperfection and PBR packs from [ambientCG](https://ambientcg.com/). They replace earlier synthetically generated 256×256 noise maps and are sampled via triplanar projection (`MaskEffectKind::Fill`) by built-in Smart Masks and lowered `.spmsk` masks.
