Mask thumbnail geometry and baked mesh maps restored byte-for-byte from the mfPainter reference (`feat/environment-preflight-mac`, `assets/procedurals/shaderball-jl01-*.png`). These are preview surface inputs, not mask archives or pre-rendered mask thumbnails. The native CPU/GPU evaluators render each mask on this surface. Generated material and smart-material previews use the same JL01 surface. The source mesh is also selectable in New Project. `preview-studio-0.png` through `preview-studio-8.png` are linear RGBE lighting maps baked from Mattias Lind’s bundled `assets/environments/default-studio.hdr` (same bytes as the mfPainter environment). Reproduce with `scripts/generate-studio-preview.py` using NumPy, Pillow and OpenCV. Levels 0–7 are GGX reflection roughness levels; 8 is cosine-weighted diffuse lighting. PNG alpha stores the RGBE exponent, not coverage. The sampler applies the reference camera-to-Z-up conversion and +90° Z rotation; the source HDR is never modified.
